## What is skip logic?

Skip logic (also called conditional display) means a field is only shown on screen when a prior
answer satisfies a specified condition. If the condition is not met, the field is hidden and the
clinician never enters a value. In the cleaned dataset these fields become NA. This NA is
**intentional and structurally meaningful** -- it is coded as `-7` (Not Applicable) in the
NA-reason module (Module 16).

## Condition syntax

| Syntax element | Meaning |
|---|---|
| `$FieldKey` | Value of a previously answered field |
| `= 'value'` | Equals (case-sensitive string match) |
| `!= 'value'` | Does not equal |
| `and` / `or` | Logical AND / OR |
| `!$Field = 'val'` | Negation prefix |
| `true` / `false` | Boolean values |
